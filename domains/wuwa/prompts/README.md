# prompts/

**日本語** ｜ [English](README.en.md) ｜ [中文](README.zh-CN.md)

鳴潮ドメインパックのプロンプトを置きます。

| ファイル | 内容 |
|---|---|
| `system.md` | ドメインのシステムプロンプト。コアの規則（`core/agent/prompts/core.md`：数値はツールから・回答はプレースホルダのテンプレート）の後ろに連結される |

方針:

- プロンプトに数値（倍率・確率など）を書きません。数値は必ずツールの結果から取ります（ADR-0001）。
- 数値の扱い（出典 ID の引用・比較ツール）はコアの規則に書き、ここにはドメインの文脈（ツールの使い分け・用語・データ参照）だけを書きます。
- プロンプトは版管理し、変更したら評価（`python -m core.evals`）を通します。
