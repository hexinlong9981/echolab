# ADR-0011：网页界面与公开方针（零费用）

- 状态：采用
- 日期：2026-10-04

## 背景

M5 要做对话、执行轨迹回放、评估看板和公开演示（[ADR-0007](0007-优先纵向切片.md)）。
回答需要 LLM（收费）、Java 计算服务和 OCR，所以要做"谁都能现场提问"的公开演示，就需要一直运行的服务器和 API 费用。
用户的方针是**费用最优先，最好完全免费**。

## 决定

根据用户的决定（2026-10-04）。

| 项目 | 决定 |
|---|---|
| 公开的内容 | **只有静态的回放与评估看板**。不运行服务器和 LLM |
| 实时界面 | **只在本机**（`python -m servers.web_api`，`127.0.0.1`）。面试时通过共享屏幕使用。真实 Claude 遵守核心的成本上限 |
| 托管 | **Cloudflare Pages**（免费方案） |
| 界面技术 | **React + TypeScript + Vite**，流程图用 React Flow |
| 发布方式 | **GitHub Actions**：数据导出・类型检查・测试・构建都通过后用 wrangler 发布。没有 Secrets（`CLOUDFLARE_API_TOKEN`・`CLOUDFLARE_ACCOUNT_ID`）时只跳过发布 |

- 回放数据由 CI 用剧本模式（无需 API 密钥、测试用计算服务）导出（`python -m servers.web_api.export`）。每次运行内容相同，不包含本机的绝对路径。界面上也注明这是剧本模式的记录。
- 本机 API 只用 Python 标准库（不增加依赖）。为了不被其他网站的页面调用而花掉费用，要求 `Content-Type: application/json` 并检查 `Origin`。只能使用固定的演示剧本。
- 界面文字用日语（与 CLI・评估相同）。

## 理由

- 公开演示背后放真实 LLM，即使设了费用上限，也会因第三方使用而达到上限，导致演示本身停止。静态回放既没有费用也没有风险。
- 本项目的看点（出处表・退回・拒绝）用回放逐步展示，比实时回答更容易传达。
- 有了本机界面，面试中"现场换个问题"也能应对（有 API 密钥时）。
- 在 CI 中构建后再发布，公开的数据总与该提交的测试和评估一致。

## 否决的方案

| 方案 | 否决理由 |
|---|---|
| 公开的实时演示（服务器＋真实 Claude） | 服务器与 API 费用，第三方消耗费用。也没有能一直免费运行的托管 |
| 公开的实时演示（服务器＋剧本 LLM） | 剧本不读问题，无法回答自由提问。能展示的与静态回放相同，却需要服务器 |
| GitHub Pages | 免费且已在使用，但按用户的决定沿用原计划的 Cloudflare Pages |
| 在 Cloudflare 端构建（连接仓库） | 导出数据需要 Python，而且可能在测试前就发布 |
| 本机 API 用 FastAPI | 增加依赖；标准库就足够 |

## 影响

- 新位置：`web/`、`servers/web_api/`、`.github/workflows/web.yml`。
- 要发布，需要用户注册 Cloudflare 账号并登记两个 Secrets（步骤见 `web/README.zh-CN.md`）。
- 公开的回放只有剧本模式的记录。是否公开真实 LLM 的记录，等做了真实评估时再决定。
- 测试：`tests/test_web_api.py`（导出・API 的检查）、`web/src/replay.test.ts`（回放步骤的组装，Vitest）。

## 补记（2026-10-04）：Cloudflare Pages 已并入 Workers

用 wrangler 4 创建 Pages 项目时，得到的是 Workers 项目（Cloudflare 已把 Pages 并入 Workers）。
因此把 `web/dist` 作为 Workers 的**静态资源**，用 `wrangler deploy` 发布（`web/wrangler.jsonc`；没有 Worker 代码）。
静态资源的请求在免费方案中免费，零费用的方针不变。公开地址：<https://echolab-web.echolab-web.workers.dev/>
API 令牌用模板「Edit Cloudflare Workers」创建。wrangler 自动想加入的构建改动（`@cloudflare/vite-plugin`）不采用（只提供静态文件，不需要）。
