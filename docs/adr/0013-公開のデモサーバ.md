# ADR-0013: 公開のデモサーバ（Hugging Face Spaces・台本の LLM・実物の計算サービス）

- 状態: 採用
- 日付: 2026-10-04

## 背景

M5 の公開サイトは静的なリプレイだけで、記録は CI が台本モードと**試験用の計算サービス**で作ったものだった（[ADR-0011](0011-Web-UIと公開の方針.md)）。
面接官に「計算サービスが本当に動いている」ことを見せるには、実物の計算サービス（Java の calc-engine・OCR・無職転生・住宅ローン）をその場で動かすサーバが要る。
利用者の方針は引き続き**費用をゼロ**に保つこと。実物の Claude を公開すると費用が出るので、今回は扱わない（利用者の判断：まず「A：台本の LLM ＋実物のサービス」）。

## 決定

| 項目 | 決定 |
|---|---|
| 置き場所 | **Hugging Face Spaces**（Docker・無料の CPU。クレジットカード不要） |
| 動かすもの | `python -m servers.web_api --public`。決まったデモだけを、実物の計算サービスと**台本の LLM** で実行する。実物の Claude（`anthropic`）は常に拒み、API キーを置かない |
| 制限 | 同時 1 件・待ち 3 件まで（超えたら 503）、接続元ごとに 1 分 6 回・1 日 60 回（超えたら 429）、1 件 120 秒まで |
| ブラウザから | 公開のリプレイのサイトの `Origin` にだけ CORS を返し、事前確認（OPTIONS）に応える。許可していない `Origin` の POST は 403 |
| 応答 | 静的なリプレイと同じ形の記録（手元の絶対パスを除く）＋実行時間。トレースは実行ごとの一時ディレクトリに置いて消す |
| 画面 | デモのリプレイの下に「サーバで実際に実行」。URL はビルドのときの `VITE_LIVE_API`（無ければボタンを出さない） |
| 公開の方法 | `.github/workflows/hf-space.yml` が `deploy/hf/Dockerfile` と実行に要るディレクトリだけを Space に送る（Secret `HF_TOKEN`・Variable `HF_SPACE` が無ければ飛ばす） |

コアは変えない（公開の方式は `servers/web_api/public.py` だけ）。

## 理由

- 台本の LLM でも、計算はすべて実物のサービスが行う。「数値はツールから」（ADR-0001）が本物の Java・OCR の上で成り立っていることを、その場で示せる。
- 実物の Claude を置かないので、第三者に使われても費用は出ない。回数の上限と同時 1 件は、無料の CPU を占有されないためのもの。
- Docker なら Java 21・Tesseract・Python を 1 つの像にまとめられる。Hugging Face Spaces はクレジットカードなしで Docker を動かせる。

## 却下した案

| 案 | 却下した理由 |
|---|---|
| Cloudflare Workers | 子プロセス（Java・Tesseract）を起動できない |
| Render の無料プラン | メモリが小さく、Java と OCR を同時に動かすには心もとない。休止もある |
| Google Cloud Run・Oracle Cloud の無料枠 | 登録にクレジットカードが要る |
| 実物の Claude を公開する | 費用が出る（利用者の方針に反する）。必要になったら、合言葉・小さな日次の上限つきで別に決める |
| 静的なリプレイだけのまま | 実物のサービスが動いていることを示せない |

## 影響

- 新しい場所：`servers/web_api/public.py`、`deploy/hf/`、`.dockerignore`、`.github/workflows/hf-space.yml`。
- 無料の CPU は使われないと休止し、次の呼び出しで起動する（画面は「起動を待っています」と表示する）。手元の Docker では、起動に約 7 秒、デモ 1 件に 2.5〜10 秒（Java の起動を含む）。
- 公開には、利用者が Hugging Face のアカウント・Space・書き込み用のトークンを用意し、`HF_TOKEN`・`HF_SPACE`・`LIVE_API_URL` を登録する（`web/README.md`）。
- 試験：`tests/test_web_api.py`（台本以外の拒否・CORS と事前確認・回数の上限・待ちの上限・パスを出さない）、`web/src/liveApi.test.ts`。
