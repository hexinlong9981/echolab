使用参考

命令参考

EchoLab 目前提供两个命令：提问用的 python -m core.agent 和评估用的 python -m core.evals。本页列出它们的全部选项、运行模式、输出格式、状态与退出码、环境变量。

前提所有命令都在仓库根目录、已激活虚拟环境（source .venv/bin/activate）的状态下执行。提问只能用命令行；网页界面见本页的 python -m servers.web_api 一节。

python -m core.agent（提问）

参数 / 选项默认值说明
question（必填）—问题文本。含空格时用引号括起来。要读截图时，把图片路径写在问题里（M4，见能问什么）。缺少时 argparse 报 error: the following arguments are required: question，退出码 2。
--domain DOMAINwuwa领域包（读取 domains/<DOMAIN>/domain.yaml）。目前有 wuwa（鸣潮）、mushoku（《无职转生》设定考证，示例台本 domains/mushoku/examples/teleport_age.yaml，需要 --context progress=…）和 mortgage（住宅贷款还款的计算示例，示例台本 domains/mortgage/examples/compare_methods.yaml）。指定不存在的领域时，无论是否加 --fake-backend，都输出 エラー: ドメインが見つかりません: <DOMAIN>（使えるドメイン: mortgage、mushoku、wuwa），退出码 2。
--context NAME=VALUE—由你（而不是 AI）指定的项目，可以写多次。只接受领域包在 domain.yaml 的 user_context 里声明的名字；目前只有 mushoku 的 progress（你的进度：novel:<卷> 或 anime:<期>-<集>，例 --context progress=novel:5）。AI 看不到这个值，也改不了。写成别的名字时输出 エラー: ドメイン mushoku は利用者の指定 foo を受け付けません（受け付ける項目: progress），退出码 2；格式不对时报 エラー: --context は NAME=VALUE の形で指定してください: …。
--llm {anthropic,scripted}anthropicanthropic：调用真实 Claude（模型 claude-opus-5-5），需要凭据。scripted：按台本文件回放，不需要凭据。
--script SCRIPT—台本 YAML 文件路径（相对路径以当前目录为基准）。--llm scripted 时必填，缺少时输出 エラー: --llm scripted には --script（台本の YAML）が必要です；文件不存在时输出 エラー: 台本が見つかりません: <路径>。两者退出码都是 2。项目自带示例：core/agent/examples/compare_builds.yaml。
--fake-backend关闭不启动 Java 计算服务，改用测试用的 Python 参考实现。可与任一 --llm 组合。注意：假服务不提供 gacha_simulate（蒙特卡洛）工具。
--trace-dir TRACE_DIR.echolab/traces执行轨迹（JSONL）的保存目录。相对路径以仓库根目录为基准。
--debug关闭设置或启动出错（退出码 2）时，除了简短的说明，还打印 Python 的 Traceback。平时不需要；排查问题或报告缺陷时使用。
-h, --help—显示帮助并退出（退出码 0）。

运行模式

--llm 决定「谁扮演 AI」，--fake-backend 决定「谁做计算」。两者可以自由组合：

组合需要 API 凭据需要 JDK + jar会产生费用用途
--llm scripted --script … --fake-backend否否否最快的演示；只需 Python
--llm scripted --script …否是否确认 Java 计算服务能正常工作
--fake-backend（即 anthropic）是否是没装 JDK 但想自由提问
不加任何选项（默认）是是是正式使用：真实 Claude + 真实计算服务
 
flowchart LR
  Q["你的问题"] --> L{"--llm"}
  L -- "anthropic（默认）" --> C["真实 Claude<br/>claude-opus-5-5"]
  L -- scripted --> S["台本 YAML<br/>按步骤回放"]
  C --> G["网关<br/>许可名单・参数检查・费用上限"]
  S --> G
  G --> B{"--fake-backend?"}
  B -- 否 --> J["Java 计算服务<br/>calc-engine-mcp.jar"]
  B -- 是 --> P["Python 参考实现<br/>（测试用假服务）"]
图 1：两个开关分别替换「AI」和「计算」。网关、校验器、出典表在所有模式下都一样工作
台本模式用一次性的台账台本里的用量是虚构的，所以 --llm scripted 时 CLI 把用量记到每次运行专用的临时台账里，运行结束即删除，不会写入真实台账 .echolab/costs.jsonl（与 python -m core.evals 的台本模式相同；--help 末尾也有说明）。上限的检查仍然照常进行：把 ECHOLAB_DAILY_USD 设为 0 时，台本模式也会以 budget_exceeded 结束。只有 --llm anthropic 使用真实台账。

输出的结构

每次运行都按同一结构输出到标准输出：

（带 ↑ 的灰色行是本说明加的标注，不是程序输出。）

部分内容
① 回答通过校验、填入数字后的回答；未通过时是一句固定文本（见下方状态表）。计算用了未确认数据时，末尾多一行 ※ この回答の数値の一部は、未確認のサンプルデータに基づいています。
② 出典表列：出典 ID（c<第几次调用>.<结果字段>）、値（工具返回的原始值）、ツール（工具名）、未確認データ（用到的未确认数据 ID，没有则 -）。状态不是 answered 时显示 （引用した出典はありません）。
状態运行结果状态，见下节。
差し戻し: N 回草稿被校验器退回的次数。
費用: $x.xxxx本次运行中调用 Claude 的费用（美元，显示 4 位小数）。台本模式为 $0.0000。
実行 ID运行 ID，格式为 UTC 时间戳加 6 位十六进制，如 20261003T024449Z-4423a9。
トレース本次运行的执行轨迹文件（<trace-dir>/<実行 ID>.jsonl）。查看方法见 执行轨迹与评估。

运行状态与退出码

状态（状態）一共 7 种。只有 answered 的回答里含有来自工具的数字；其他状态都给出固定文本，不含计算结果（budget_exceeded 里的金额来自费用台账和设置，不是 AI 写的）。

状态何时出现屏幕上的回答（原文）退出码
answered草稿通过校验填好数字的回答 + 出典表0
fallback草稿被退回后再重写，累计退回 3 次（允许重写 2 次）仍不合格申し訳ありません。計算結果の出典を確かめられる回答を作れなかったため、数値を含む回答は控えます。条件を具体的にして、もう一度質問してください。1
budget_exceeded调用 AI 之前发现今天或本月的费用已达上限写明是哪个上限、已用金额与上限、何时恢复、怎么修改，例如：今日（UTC）のコストが日次の上限に達したため、今は回答できません（使用額 1.02 USD / 上限 1.00 USD）。UTC の日付が変わると使えるようになります。上限は環境変数 ECHOLAB_DAILY_USD か config/budget.yaml の caps_usd.daily で変えられます。（月上限时为 今月（UTC）…月次の上限…ECHOLAB_MONTHLY_USD…caps_usd.monthly）1
llm_error调用 Claude 失败。按 SDK 的异常类型分 4 类，回答各不相同没有凭据：Claude API の認証情報が見つからないため、回答できませんでした。環境変数 ANTHROPIC_API_KEY を設定する（または ant auth login でログインする）か、API キーの要らない台本モード（--llm scripted）をお使いください。
认证失败（HTTP 401/403）：Claude API の認証に失敗したため、回答できませんでした。ANTHROPIC_API_KEY（または ant auth login のログイン）が有効かを確かめてください。
限流・过载・网络：Claude API が混み合っているか、接続できなかったため、回答できませんでした。時間をおいてお試しください。
其他 API 错误：Claude API の呼び出しに失敗したため、回答できませんでした。詳細はトレースの llm_error の行を確かめてください。		1
refusal模型的安全机制停止了回答この質問には回答できませんでした（モデルの安全機能により応答が止まりました）。1
max_tokensAI 的输出太长被截断応答が長くなりすぎて途中で切れたため、回答を完成できませんでした。質問を分けてお試しください。1
tool_round_limit调用工具的轮数超过 6 轮計算の手順が多くなりすぎたため、回答を完成できませんでした。質問を分けてお試しください。1

其他退出情形

情形表现退出码

python -m core.evals（忠实度评估）

把 evals/faithfulness/cases.yaml 中的 8 个评估用例逐个跑一遍，统计回答里有没有「没有出处的数字」。默认用台本模式和假计算服务，不需要密钥和 Java。

选项默认值说明
--llm {scripted,anthropic}scripted注意默认值与 core.agent 相反。scripted 时使用假计算服务和一次性的临时台账；anthropic 时使用真实 Claude、Java 计算服务和真实台账（会产生费用）。
--cases CASESevals/faithfulness/cases.yaml用例文件。
--out OUT—把 Markdown 报告另存到该文件（不指定时只打印到屏幕）。
--raw-dir RAW_DIRevals/reports/raw原始记录（每个用例一行 JSONL）和各用例轨迹（traces/ 子目录）的保存位置。
--case ONLY全部只运行指定 ID 的用例；可重复指定多次。指定了不存在的 ID 时一个用例也不运行，列出可用的 ID 并以退出码 2 结束。
--debug关闭设置或启动出错时同时打印 Traceback（与 core.agent 相同）。

退出码：所有用例都「合格」时为 0，有不合格时为 1，--case 的 ID 写错等用法错误时为 2：

指标含义见 执行轨迹与评估。

python -m servers.web_api（网页界面）

在浏览器里回放执行轨迹、查看评估看板（M5）。三条命令：

python -m servers.web_api.export                 # 剧本模式运行全部演示与评估 → web/public/data/
(cd web && npm ci && npm run build)              # 构建网页 → web/dist/（需要 Node.js）
python -m servers.web_api                        # 只监听 127.0.0.1 → http://127.0.0.1:8765/
标签页内容
回放用流程图逐步播放执行轨迹：经过的方框、退回、拒绝用颜色标出，并显示当时的出典表。网址 #replay/<键>/<步>（键是演示的 ID 或「评估 ID-用例 ID」，重新发布也不变，例如 demo-compare-builds） 可直接打开某一步
评估忠实度（鸣潮・住宅贷款）与注入评估的指标和每个用例的结果，可跳到回放
运行（本机）只在通过 python -m servers.web_api 打开时出现：运行剧本演示，或（有 API 密钥时）向真实 Claude 提问，受费用上限保护

选项：--port（默认 8765）。这个服务只在本机使用，不要对外公开。公开的回放网站是 CI 生成的静态文件（Cloudflare（Workers 的静态资源，原 Pages）：https://echolab-web.echolab-web.workers.dev/）。详见仓库的 web/README.zh-CN.md。

--public（公开的演示服务器，M7）

python -m servers.web_api --public [--host 0.0.0.0] [--port 7860]

作为公开的演示服务器运行（ADR-0013）：只能运行固定的演示，用真实计算服务和剧本 LLM；始终拒绝真实 Claude。同时 1 个、每个来源每分钟 6 次・每天 60 次，只对允许的网站（公开的回放网站）返回 CORS。提供 GET /api/health 和 POST /api/ask {"demo": "<演示 ID>"}。平时由 Hugging Face Spaces 上的 Docker 镜像（deploy/hf/Dockerfile）运行，网页回放下方的「在服务器上实际运行」会调用它。

环境变量

变量默认（来源）作用
ANTHROPIC_API_KEY无真实 Claude 的 API 密钥。也可以改用 ant auth login 等 Anthropic SDK 支持的其他凭据方式。仅 --llm anthropic 时使用。
ECHOLAB_DAILY_USD1.00（config/budget.yaml）每天（UTC）的费用上限，美元。
ECHOLAB_MONTHLY_USD10.00（config/budget.yaml）每月（UTC）的费用上限，美元。
ECHOLAB_LEDGER.echolab/costs.jsonl（config/budget.yaml）费用台账文件。相对路径以仓库根目录为基准。只用于 --llm anthropic；台本模式每次用一次性的临时台账。
JAVA_HOME无PATH 上找不到 java 时，改用 $JAVA_HOME/bin/java 启动计算服务。
PATH系统优先从 PATH 查找 java。
ECHOLAB_DATA_ROOTdomains（config/services.yaml）Java 计算服务读取示例数据的根目录。config/services.yaml 里的 domains 只是默认值：shell 中设置了同名变量时，CLI 启动服务时优先使用 shell 的值（例如 ECHOLAB_DATA_ROOT=/path/to/data python -m core.agent …）。一般无需设置。
