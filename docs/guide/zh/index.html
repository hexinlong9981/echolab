开始概览

EchoLab 是什么

一个「不让 AI 自己算数」的命令行问答助手：你用一句话提问，数字全部由确定性的计算工具算出，回答里每个数字都能查到出处。

它能帮你做什么

EchoLab 以游戏《鸣潮（Wuthering Waves）》的养成为题材（非官方、非营利的同人作品）。你在终端里输入一个问题，它会：

  • 理解你的问题，挑选合适的计算工具（期望伤害、声骸评分、抽卡概率，以及求差、求增长率的比较工具）；
  • 让工具算出结果，再用这些结果写成一段说明；
  • 在回答下方附上出典表：每个数字来自哪次计算、原始值是多少、是否用到了未确认的数据。
目前只有命令行（CLI）EchoLab 现在只能在终端里用 python -m core.agent "问题" 提问，没有图形界面。Web 界面是路线图 M5 的计划，尚未实现（见 今后的功能（路线图））。
关于界面语言CLI 的提示与输出（如 状態、出典、差し戻し）是日语。本说明原样展示真实输出，并用中文解释每一部分。示例问题也沿用项目自带的日语示例。

为什么它的数字可信

数字只来自工具

AI 不做任何算术，连两个数的差、增长率也交给比较工具（compare.diff / compare.ratio）计算。

校验器逐个核对

AI 写的是带占位符的草稿（如 [[c1.total|0]]）。草稿里出现没有出处的数字，就被「差し戻し」（退回重写）。

出典表可追溯

每个数字都有出典 ID（如 c3.diff），在回答下方列出原始值和计算工具。

未确认数据会标注

示例数据大多是 verified: false。用到它们时，回答末尾会自动加注「未確認のサンプルデータに基づいています」。

改不对就不给数字

退回 3 次仍不合格，就只给一句不含数字的固定回答（状态 fallback），而不是给出可疑的数字。

费用有上限

调用真实 Claude 时，每天 1 美元、每月 10 美元的上限会在每次调用前检查（可用环境变量调整）。
