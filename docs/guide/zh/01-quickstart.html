第 1 步：取得代码

git clone https://github.com/hexinlong9981/echolab.git
cd echolab

第 2 步：Python 虚拟环境与依赖

只为使用 CLI，安装 requirements.txt 就够了（requirements-dev.txt 额外包含 pytest、ruff 等开发工具）。

看到帮助信息就说明安装成功。以后每次新开终端，先在仓库根目录执行 source .venv/bin/activate，下文的 python 都指虚拟环境里的 Python。

第 3 步：第一次提问（无需密钥、无需 Java）

两个开关让演示完全在本机运行：

  • --llm scripted --script 台本.yaml：不调用真实 AI，按台本文件里写好的步骤「扮演」AI。
  • --fake-backend：不启动 Java 计算服务，改用测试用的 Python 参考实现计算。
台本模式的回答是事先写好的台本模式只是演示：AI 调哪些工具、写什么草稿都由台本决定，与你输入的问题无关。比如把问题换成「こんにちは」，用同一个台本仍然会得到上面同样的回答。真正「理解问题」需要第 5 步的真实 Claude。

注意 差し戻し: 1 回：这个台本故意让第一版草稿写了一个自己算的数字（936），被校验器退回，第二版改用比较工具后才通过。

第 4 步：接上真实的 Java 计算服务

去掉 --fake-backend 后，CLI 会按 config/services.yaml 以子进程方式启动 java -jar services/calc-engine/build/libs/calc-engine-mcp.jar。因此需要 JDK 21 和构建好的 jar。

  1. 安装 JDK 21（发行版的包或 Temurin 压缩包均可）。下例把 JDK 解压在 $HOME/.local/jdk/21。
  2. 设置 JAVA_HOME。即使 java 不在 PATH 上，只要 JAVA_HOME 指向 JDK，CLI 也会改用 $JAVA_HOME/bin/java。
  3. 在 services/calc-engine 下构建 jar（第一次会下载 Gradle 及依赖，需要联网）。

然后用同样的问题和台本、但不加 --fake-backend 再问一次。由于要启动 Java 进程，验证环境中整次运行约需 9 秒。

回答和出典表都与第 3 步完全相同：假服务也和 Java 服务一样，把期待伤害等数值按小数 6 位（银行家舍入 HALF_EVEN）返回，例如 6192.000000。命令中的「…（同上）…」表示省略，实际要输入完整的问题。

如果报 エラー: サービス calc-engine の実行ファイル java が見つかりません。说明既找不到 PATH 上的 java，也没有设置 JAVA_HOME；如果报 jar がありません，说明还没构建 jar。两种情况 CLI 都会在启动 Java 之前停下，只打印一段说明和修复方法，退出码为 2。见 故障排除与 FAQ。

第 5 步（可选）：使用真实的 Claude

不加 --llm 时默认就是 anthropic，即调用真实的 Claude（模型 claude-opus-5-5）。这时你可以自由提问，Claude 会自己决定调用哪些工具。

5-1 准备凭据

凭据按 Anthropic 官方 Python SDK 的默认顺序查找。最简单的两种：

# 方式 A：环境变量
export ANTHROPIC_API_KEY=sk-ant-...（你的密钥）

# 方式 B：用 Anthropic 的 CLI 登录（SDK 会读取它保存的配置）
ant auth login

没有凭据时运行会怎样？下面是实际输出：CLI 不会崩溃，而是以状态 llm_error 结束，退出码为 1，回答里直接写明原因（没有认证信息）和解决办法。

回答按原因区分llm_error 的回答会按 SDK 的异常类型给出不同的提示：没有凭据或认证失败（HTTP 401/403）时提示设置 ANTHROPIC_API_KEY 或 ant auth login；限流、过载、网络问题时才提示「時間をおいてお試しください」（请稍后再试）；其他 API 错误则提示查看轨迹。轨迹的 llm_error 行里有分类 kind 和 SDK 的原始错误信息。

5-2 先设好费用上限

每次调用 Claude 之前，CLI 都会检查费用台账（默认 .echolab/costs.jsonl）。默认上限在 config/budget.yaml：每天 1.00 美元、每月 10.00 美元，按 UTC 划分日期（北京时间每天 8:00 换日）。第一次试用时可以临时调得更低：

export ECHOLAB_DAILY_USD=0.20     # 今天最多 0.20 美元
export ECHOLAB_MONTHLY_USD=2.00   # 本月最多 2.00 美元

达到上限时不会再调用 Claude，而是以状态 budget_exceeded 结束。费用的计算方式和台账格式见 成本上限与数据可信度。

5-3 提问

python -m core.agent "攻撃力 2000、スキル倍率 2.5、ダメージバフ 0.3、会心率 0.6、会心ダメージ 2.2、防御定数 1600、敵の防御 1000、防御無視 0、敵の耐性 0.1、耐性ダウン 0 のときの期待ダメージを、明細つきで教えて。"

（本说明的验证环境没有 API 密钥，因此这里不展示真实 Claude 的回答；回答的格式与上面台本模式相同。）计算需要的参数最好都写进问题里——工具只能用你给出的数值或项目自带的示例数据来计算。

隐私只有在 anthropic 模式下，你的问题、系统提示和工具的计算结果才会发送给 Anthropic。台本模式完全在本机运行。每次运行的轨迹都保存在本机的 .echolab/traces/。
