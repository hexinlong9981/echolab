M3（已完成）：第二个领域包——住宅贷款还款的计算示例

EchoLab 的核心（网关、验证器、评估、轨迹）不包含任何游戏概念；领域知识都放在“领域包”里，用 domain.yaml 声明可用工具。M3 用一个很小的住宅贷款包证明了这一点：

  • 内容：等额本息（元利均等）与等额本金（元金均等）的比较、部分提前还款（缩短期限型・减少月供型）的效果。计算由领域包里的 Python MCP 服务器完成，不需要 Java；同样带黄金测试用例、提示词和台本评估（5 个用例）。
  • 核心零改动：加这个包的提交没有改动 core/，CI 的 pack-isolation 作业每次都检查这一点。加包之前缺的 3 个通用功能（启动 Python 服务、按领域运行评估、回答注记）先以单独的提交加进了核心（ADR-0009）。
  • 每个通过验证的回答末尾都会自动加上：这是计算示例，不是金融建议。

对你意味着：用 --domain mortgage 就能切换到住宅贷款（默认仍是 wuwa）。不需要 API 密钥的试用方法：

python -m core.agent "3000 万円を年 1.5%、35 年で借りるとき、元利均等と元金均等では利息の合計はどれだけ違う？" \
  --domain mortgage --llm scripted --script domains/mortgage/examples/compare_methods.yaml

M4（已完成）：截图读取与注入评估

部分作用
servers/vision_mcp/用 OCR（Tesseract）读取截图的 MCP 服务器（Python，与领域无关）。读什么由领域包的模板（domains/wuwa/vision/echo_screenshot.yaml）决定，只返回模板里声明的数值字段（如 sub_crit_rate）。图片里的其他文字一律丢弃，传不到 Claude。超出范围的值（疑似误读）报错，不会被猜测补全
图片路径的限制只能读 ECHOLAB_VISION_ROOTS（默认是仓库目录）里的 PNG・JPEG，不超过 10 MB。/etc/passwd 之类的路径会被拒绝
evals/redteam/7 个提示词注入的评估题：用剧本模拟“Claude 被骗了”的情况（照着图片写数字、调用未声明的工具、读允许范围外的文件……），确认读取・网关・验证器仍然拦得住。使用合成的截图，不使用游戏图片。在 CI 中每次运行：7/7 通过，没有一个攻击成功

使用前需要安装 Tesseract 和日语数据（例：sudo dnf install tesseract tesseract-langpack-jpn，或 sudo apt-get install tesseract-ocr tesseract-ocr-jpn）。截图的路径直接写在问题里。不需要 API 密钥的试用方法（还需要 Java 计算服务；加 --fake-backend 则改用记录好的 OCR 结果）：

python -m core.agent "evals/redteam/screenshots/echo-injection.png の声骸を採点して。重みは会心率 1.0・会心ダメージ 1.0・攻撃力% 0.75・攻撃力 0.25・共鳴効率 0.5、最大値は会心率 0.1・会心ダメージ 0.2・攻撃力% 0.12・攻撃力 60・共鳴効率 0.12 として。" \
  --llm scripted --script domains/wuwa/examples/score_screenshot.yaml

尚未做的：用真实 Claude 跑注入评估（只在本地手动运行，需要 API 密钥）。

M5（已完成）：网页界面

web/ 目录用 React + TypeScript + Vite 做成。方针是费用最优先、完全免费（ADR-0011）：公开的只有静态网站，不运行服务器，也不调用 Claude，所以既没有费用，也不会被别人刷掉 API 费用。

回放

把执行轨迹画成流程图（React Flow）逐步播放：经过哪个方框、哪一稿被退回、哪个工具被拒绝，都用颜色标出，并显示当时已有的出典表。网址 #replay/<执行 ID>/<步> 可以直接打开某一步。

评估看板

数值忠实度（鸣潮・住宅贷款）和注入评估的指标与每个用例的结果；每个用例都能跳到回放。

运行（只在本机）

在自己电脑上用 python -m servers.web_api 打开时才出现：可以运行剧本演示，有 API 密钥时还能向真实 Claude 提问（受日／月成本上限保护）。只监听 127.0.0.1，不对外公开。

公开网站

托管在 Cloudflare（Workers 的静态资源，原 Pages）（免费方案）：https://echolab-web.echolab-web.workers.dev/。CI 用剧本模式生成数据、构建并发布；公开的回放是剧本模式的记录，不是真实 Claude 的回答。推送到 main 后自动重新发布，要等作者把 API 令牌加入 GitHub Secrets 后才开始。

在自己电脑上试用（需要 Node.js）：

python -m servers.web_api.export && (cd web && npm ci && npm run build)
python -m servers.web_api        # 浏览器打开 http://127.0.0.1:8765/

不会改变的东西

无论是新的领域、截图输入还是网页界面，都会走同一条核心流程。所以对你来说，下面这些保证会一直保持：

数字只来自计算工具

AI 只写带 [[出典ID]] 的模板，数字由程序填入。

验证器把关

来历不明的数字会被退回；改不好就给出不含数字的说明。

出典可查

每个数字都能追到工具和原始值，并留在执行轨迹里。

成本有上限

达到每日 / 每月上限就不再调用 Claude。

未确认数据有注记

用到示例数据的数值会自动提醒。
