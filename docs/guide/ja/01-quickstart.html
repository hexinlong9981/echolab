ステップ 1：コードを取得する

git clone https://github.com/hexinlong9981/echolab.git
cd echolab

ステップ 2：Python の仮想環境と依存パッケージ

CLI を使うだけなら、requirements.txt のインストールで足ります（requirements-dev.txt には pytest や ruff などの開発用ツールが追加で入っています）。

ヘルプが表示されればインストールは成功です。新しいターミナルを開いたら、まずリポジトリのルートで source .venv/bin/activate を実行してください。以下の python はすべて仮想環境の Python を指します。

ステップ 3：最初の質問（API キーも Java も不要）

次の 2 つのオプションで、デモを手元だけで完結させます。

  • --llm scripted --script 台本.yaml：実際の AI を呼ばず、台本ファイルに書かれた手順どおりに AI の役を「演じ」ます。
  • --fake-backend：Java 計算サービスを起動せず、試験用の Python の参照実装で計算します。
台本モードの回答はあらかじめ決まっています台本モードはデモ用です。AI がどのツールを呼び、どんな下書きを書くかは台本で決まっていて、入力した質問とは関係ありません。たとえば質問を「こんにちは」に変えても、同じ台本なら上と同じ回答が返ります。質問を本当に「理解」させるには、ステップ 5 の実際の Claude が必要です。

差し戻し: 1 回 に注目してください。この台本では、1 回目の下書きにわざと自分で計算した数字（936）を書かせています。それが検証器に差し戻され、2 回目に比較ツールを使って書き直したことで合格しています。

ステップ 4：実際の Java 計算サービスにつなぐ

--fake-backend を外すと、CLI は config/services.yaml に従い、java -jar services/calc-engine/build/libs/calc-engine-mcp.jar を子プロセスとして起動します。そのため JDK 21 とビルド済みの jar が必要です。

  1. JDK 21 をインストールします（ディストリビューションのパッケージでも Temurin のアーカイブでもかまいません）。以下の例では $HOME/.local/jdk/21 に展開しています。
  2. JAVA_HOME を設定します。java が PATH になくても、JAVA_HOME が JDK を指していれば、CLI は $JAVA_HOME/bin/java を使います。
  3. services/calc-engine で jar をビルドします（初回は Gradle と依存ライブラリをダウンロードするため、ネットワーク接続が必要です）。

続いて、同じ質問と台本で、--fake-backend を付けずにもう一度質問します。Java のプロセスを起動するため、検証環境では 1 回の実行に約 9 秒かかりました。

回答も出典の表もステップ 3 とまったく同じです。試験用の計算サービスも Java のサービスと同じく、期待ダメージなどの数値を小数点以下 6 桁（銀行丸め HALF_EVEN）で返します（例：6192.000000）。コマンド中の「…（同上）…」は省略を表しています。実際には質問を省略せずに入力してください。

エラー: サービス calc-engine の実行ファイル java が見つかりません。 と表示されたらPATH 上に java がなく、JAVA_HOME も設定されていません。jar がありません と表示された場合は、jar がまだビルドされていません。どちらの場合も CLI は Java を起動する前に止まり、原因と直し方を表示して終了コード 2 で終わります。トラブルシューティングと FAQもご覧ください。

ステップ 5（任意）：実際の Claude を使う

--llm を指定しないときの既定値は anthropic で、実際の Claude（モデル claude-opus-5-5）を呼びます。この場合は自由に質問でき、どのツールを呼ぶかは Claude が自分で判断します。

5-1 認証情報を用意する

認証情報は、Anthropic 公式 Python SDK の既定の順序で探されます。いちばん簡単なのは次の 2 つです。

# 方法 A：環境変数
export ANTHROPIC_API_KEY=sk-ant-...（ご自分のキー）

# 方法 B：Anthropic の CLI でログイン（SDK がその保存した設定を読み込みます）
ant auth login

認証情報がないまま実行するとどうなるでしょうか。実際の出力を下に示します。CLI は異常終了せず、状態 llm_error・終了コード 1 で終わり、回答に原因（認証情報がないこと）と対処法がそのまま書かれます。

回答は原因ごとに変わりますllm_error の回答は、SDK の例外の種類に応じて案内が変わります。認証情報がない、または認証に失敗した（HTTP 401/403）ときは ANTHROPIC_API_KEY の設定か ant auth login を案内します。レート制限・過負荷・ネットワークの問題のときに限り「時間をおいてお試しください」と案内します。それ以外の API エラーでは、トレースを確認するよう案内します。トレースの llm_error の行には、分類 kind と SDK の元のエラーメッセージが記録されます。

5-2 先にコストの上限を設定する

CLI は Claude を呼ぶ前に毎回、費用の台帳（既定は .echolab/costs.jsonl）を確認します。既定の上限は config/budget.yaml にあり、1 日 1.00 ドル・1 か月 10.00 ドルです。日付は UTC で区切ります（日本時間では毎日 9:00 に日付が変わります）。初めて試すときは、一時的にもっと低くしておくこともできます。

export ECHOLAB_DAILY_USD=0.20     # 今日は最大 0.20 ドル
export ECHOLAB_MONTHLY_USD=2.00   # 今月は最大 2.00 ドル

上限に達すると Claude は呼ばれず、状態 budget_exceeded で終了します。費用の計算方法と台帳の形式はコストの上限とデータの確かさをご覧ください。

5-3 質問する

python -m core.agent "攻撃力 2000、スキル倍率 2.5、ダメージバフ 0.3、会心率 0.6、会心ダメージ 2.2、防御定数 1600、敵の防御 1000、防御無視 0、敵の耐性 0.1、耐性ダウン 0 のときの期待ダメージを、明細つきで教えて。"

（このガイドの検証環境には API キーがないため、実際の Claude の回答は載せていません。回答の形式は上の台本モードと同じです。）計算に必要なパラメータは、できるだけすべて質問に書いてください。ツールが計算に使えるのは、質問で与えた数値か、プロジェクト付属のサンプルデータだけです。

プライバシー質問、システムプロンプト、ツールの計算結果が Anthropic に送信されるのは、anthropic モードのときだけです。台本モードは完全に手元で動きます。各実行のトレースは手元の .echolab/traces/ に保存されます。
