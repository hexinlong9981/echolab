① java が見(み)つからない

原(げん)因(いん)：--fake-backend を付(つ)けていないので CLI は Java の計(けい)算(さん)サービス(service)を起(き)動(どう)しようとしますが、PATH に java がなく、JAVA_HOME も設(せっ)定(てい)されていません（CLI は子(こ)プロセス(process)を起(き)動(どう)する前(まえ)にこれを確(かく)認(にん)します）。WSL では、Windows 側(がわ)に入(い)れた Java はふつう Linux 側(がわ)からそのままでは使(つか)えません。

対(たい)処(しょ)（どれか 1 つ）：

  • JAVA_HOME を JDK 21 に向(む)けます：export JAVA_HOME=$HOME/.local/jdk/21（実(じっ)際(さい)のインストール(install)先(さき)に合(あ)わせてください）。CLI は自(じ)動(どう)で $JAVA_HOME/bin/java を使(つか)います。
  • または JDK 21 の bin を PATH に追(つい)加(か)します。
  • 当(とう)面(めん) Java を使(つか)わない場(ば)合(あい)は、--fake-backend を付(つ)けます。
