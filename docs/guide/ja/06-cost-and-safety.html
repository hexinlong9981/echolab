コストの上限とデータの確かさ

本物の Claude で質問に答えると、API の費用がかかります。EchoLab は Claude を呼ぶ前に毎回、日次・月次の 2 つの上限を確認し、呼び出しごとの費用を手元の台帳に記録します。このページでは、料金、上限、上限に達したときの動き、台帳の形式、そしてあなたのデータがどこへ送られるか、どのデータを信頼できるかを説明します。

モデルと料金

既定のモード（--llm anthropic）では claude-opus-5-5 を使います。料金表は config/budget.yaml にあり、単位は100 万トークンあたりの米ドルです：

モデル入力出力キャッシュ読み取りキャッシュ書き込み（TTL 5 分）用途
claude-opus-5-54.0020.000.205.00既定のモデル
claude-opus-55.0025.000.506.25サーバ側のフォールバックで使われることがある
claude-opus-4-85.0025.000.506.25同上

リクエストではサーバ側のフォールバック（fallbacks: "default"）を有効にしています。既定のモデルが安全性の分類器によって回答を拒否した場合、サーバが別のモデルで回答することがあります。そのとき EchoLab は試行ごとに（それぞれのモデルの料金で）記帳します。台本モード（--llm scripted）は API を一切呼びません。台本に usage が書かれていなければ費用は 0 です。台本に模擬の usage が書かれている場合、CLI は料金表からこの「模擬の費用」を計算して状態行に表示しますが、記録先はその実行専用の一時台帳（実行が終わると削除）だけで、本物の台帳には書き込みません（評価 python -m core.evals の台本モードも同じです）。

1 つの質問でおよそいくらかかるか

ここでは例のトークン数を使って計算方法を示します。この数値は evals/faithfulness/cases.yaml の damage-basic ケースの台本に書かれた usage から取ったものです（説明用の仮の値で、実測ではありません）。ダメージの質問 1 つで、LLM の呼び出しは計 2 回です。

LLM の呼び出し入力出力キャッシュ書き込みキャッシュ読み取り費用（claude-opus-5-5）
1 回目（ツールを選ぶ）2,4001802,1000$0.0237
2 回目（回答を書く）30014002,100$0.00442
合計2,7003202,1002,100$0.02812

費用はいずれも core/gateway/budget.py の Budget.cost() が上の料金表から計算したものです。この規模なら、1 日 1 ドルの上限でこうした質問をおよそ 35 回できます。実際のトークン数は、質問の長さ、ツールの呼び出し回数、下書きの差し戻し回数によって変わります。

日次の上限と月次の上限

上限既定値環境変数設定ファイル
日次1.00 USDECHOLAB_DAILY_USDconfig/budget.yaml → caps_usd.daily
月次10.00 USDECHOLAB_MONTHLY_USDconfig/budget.yaml → caps_usd.monthly
台帳の場所.echolab/costs.jsonlECHOLAB_LEDGERconfig/budget.yaml → ledger（相対パスはリポジトリのルートが基準。anthropic モードでのみ使用）
  • 環境変数は設定ファイルより優先されます。たとえば今回の実行だけ上限を緩めるには：ECHOLAB_DAILY_USD=2 python -m core.agent "…"。
  • 「今日」「今月」は UTC で区切ります。日付は毎日 UTC の 0 時（日本時間の 9 時）に変わり、月は毎月 1 日の UTC の 0 時（日本時間の 9 時）に変わります。
  • 上限は 0 以上の数値でなければなりません。abc のような値を指定すると、CLI は Claude を呼ばずに標準エラーへ エラー: 環境変数 ECHOLAB_DAILY_USD の値「abc」はコストの上限（USD）として使えません。0 以上の数値（例 1.00）を指定してください と出力し、終了コード 2 で終わります（実測。config/budget.yaml の値が不正な場合も同様にエラーになり、どのキーかを示します）。

Claude を呼ぶたびに前後で起きること

sequenceDiagram
  participant U as あなた（CLI）
  participant A as Agent
  participant B as 予算（台帳）
  participant C as Claude API
  U->>A: 質問
  loop LLM を呼ぶたびに（1 つの質問で通常 2 回以上）
    A->>B: check()
    B->>B: 台帳の今日・今月（UTC）の usd を集計
    alt 今日 ≥ 日次の上限 または 今月 ≥ 月次の上限
      B-->>A: BudgetExceeded
      A-->>U: 定型の回答、状態 budget_exceeded
    else 上限未満
      A->>C: リクエスト（プロンプト、ツール定義、会話）
      C-->>A: 応答とトークン使用量
      A->>B: record(model, usage)
      B->>B: JSONL に 1 行追記
    end
  end
  A-->>U: 回答と今回の費用
図 3：予算の確認は質問ごとではなく、LLM を呼ぶたびに行います

確認は呼び出しの前に行い、費用は呼び出しの後に分かるため、合計が上限をわずかに超えることがあります。超える分は最大で呼び出し 1 回分の費用です。超えたあとは、次の呼び出しが止められます。

上限に達したときの表示

以下は一時的な台帳を使って実際に再現したものです（台帳にはあらかじめ今日付けで 1.000000 ドルの記録を 1 行書いてあります。台帳のパスは例です）。ここでは既定の anthropic モードを使っています。予算の確認は Claude を呼ぶ前に行われ、上限に達していれば呼び出さないので、API キーがなくても再現できます。台本モードは使い捨ての一時台帳しか使わず ECHOLAB_LEDGER を読まないため、この再現には使えません。

月次の上限に達した場合は、月次の上限額と設定項目が示されます（ECHOLAB_DAILY_USD=5 ECHOLAB_MONTHLY_USD=0.5 で実測すると 今月（UTC）のコストが月次の上限に達したため、今は回答できません（使用額 1.000000 USD / 上限 0.5 USD）。UTC の月が変わると使えるようになります。上限は環境変数 ECHOLAB_MONTHLY_USD か config/budget.yaml の caps_usd.monthly で変えられます。 となります）。同じ情報は実行トレースの budget_exceeded イベントにも記録されます。このとき Claude は一度も呼ばれておらず、費用は 0 です。回答中の金額は台帳と設定から来たもので AI が書いたものではないため、評価で数値の忠実度を集計するときも、出典のない数値としては扱いません。

対処法：UTC で日付・月が変わるのを待つか、意図して上限を引き上げます（環境変数または config/budget.yaml）。「リセット」のために台帳を消すことはしないでください。台帳は実際に使った金額の記録です。

台帳ファイルの形式

台帳は JSONL で、LLM を 1 回呼ぶごとに 1 行追記されます。以下は、例のトークン数を一時的な台帳に書き込んで得た実際の内容です：

{"ts": "2026-10-03T02:00:00+00:00", "model": "claude-opus-5-5", "usage": {"input_tokens": 2400, "output_tokens": 180, "cache_creation_input_tokens": 2100, "cache_read_input_tokens": 0}, "usd": "0.0237"}
{"ts": "2026-10-03T02:00:00+00:00", "model": "claude-opus-5-5", "usage": {"input_tokens": 300, "output_tokens": 140, "cache_creation_input_tokens": 0, "cache_read_input_tokens": 2100}, "usd": "0.00442"}
{"ts": "2026-10-03T02:00:00+00:00", "model": "claude-sonnet-x", "usage": {"input_tokens": 2400, "output_tokens": 180, "cache_creation_input_tokens": 2100, "cache_read_input_tokens": 0}, "usd": "0.029625", "estimated": true}
フィールド意味
ts記録時刻（UTC、ISO 8601）。「今日」「今月」はこれで区切ります
model実際に課金されたモデル
usage4 種類のトークン数：入力、出力、キャッシュ書き込み、キャッシュ読み取り
usdこの呼び出しの費用。浮動小数点の誤差を避けるため、10 進数を文字列で保存します
estimatedモデルが料金表にない場合だけ現れ、値は true です（次の節を参照）
  • この台帳に書き込まれるのは --llm anthropic の呼び出しだけです。台本モードの模擬の使用量は実行ごとの一時台帳にだけ記録され、.echolab/costs.jsonl には現れません。
  • 台帳に読めない行があると、EchoLab はその行を読み飛ばしません（読み飛ばすと使いすぎにつながるおそれがあるため）。代わりに Claude を呼ぶ前に止まり、終了コード 2 で終わって、ファイル名と行番号を示します。例：エラー: コストの台帳 /tmp/broken.jsonl の 1 行目が読めないため、コストの上限を安全に判定できません（JSONDecodeError: Expecting ',' delimiter: line 1 column 35 (char 34)）。その行を直すか消してください（実測。Traceback は表示しません）。その行を直すか、別の場所へ移してください。

料金表にないモデル：控えめに見積もる

フォールバックの際、サーバが料金表にないモデルを返すことがあります。呼び出しはすでに課金されているので EchoLab は記帳しますが、料金表でいちばん高いモデルの料金で見積もり、"estimated": true を付けます。上の 3 行目がその例です。同じトークン数でも claude-opus-5-5 なら $0.0237 のところ、未知のモデルは最も高い料金で $0.029625 と見積もられます。こうすることで、上限の判定は厳しくなることはあっても緩くなることはありません（単に「料金を調べる」だけのときは推測をせず、Budget.cost() は未知のモデルに対して 料金表に無いモデルです（config/budget.yaml に追加してください） というエラーを返します）。新しいモデルによく出会う場合は、その料金を config/budget.yaml の pricing_usd_per_mtok に追加してください。

プライバシーについて質問の原文はそのまま Anthropic に送られ、手元の実行トレースにもそのまま書き込まれます。計算に関係のない個人情報は質問に書かないでください。トレースファイルを人と共有するときは、先に中の質問文を確認してください。

計算サービスの計算式は、Java と Python の 2 つの実装が同じゴールデンケースで照合しています。一方、ゲームの数値が正しいかどうかは、入力がどこから来たかで決まります：
