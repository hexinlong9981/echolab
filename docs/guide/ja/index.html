はじめに概(がい)要(よう)

EchoLab とは

「AI に計(けい)算(さん)させない」コマンドライン(command line)の質(しつ)問(もん)応(おう)答(とう)アシスタント(assistant)です。質(しつ)問(もん)を 1 文(ぶん)で入(にゅう)力(りょく)すると、数(すう)値(ち)はすべて決(けっ)定(てい)的(てき)な計(けい)算(さん)ツール(tool)が求(もと)め、回(かい)答(とう)に出(で)てくるどの数(すう)字(じ)についても出(しゅっ)典(てん)をたどれます。

できること

EchoLab は『鳴(めい)潮(ちょう)（Wuthering Waves）』の育(いく)成(せい)を題(だい)材(ざい)にした、非(ひ)公(こう)式(しき)・非(ひ)営(えい)利(り)のファン(fan)作(さく)品(ひん)です。ターミナル(terminal)で質(しつ)問(もん)を入(にゅう)力(りょく)すると、次(つぎ)のように動(うご)きます。

  • 質(しつ)問(もん)を理(り)解(かい)し、適(てき)切(せつ)な計(けい)算(さん)ツール(tool)（期(き)待(たい)ダメージ(damage)、声(せい)骸(がい)のスコア(score)、ガチャ(gacha)の確(かく)率(りつ)、差(さ)や増(ぞう)加(か)率(りつ)を求(もと)める比(ひ)較(かく)ツール(tool)）を選(えら)びます。
  • ツール(tool)に計(けい)算(さん)させ、その結(けっ)果(か)を使(つか)って説(せつ)明(めい)文(ぶん)を書(か)きます。
  • 回(かい)答(とう)の下(した)に出(しゅっ)典(てん)の表(ひょう)を付(つ)けます。それぞれの数(すう)字(じ)がどの計(けい)算(さん)から来(き)たか、元(もと)の値(あたい)はいくつか、未(み)確(かく)認(にん)のデータ(data)を使(つか)ったかどうかがわかります。
現(げん)在(ざい)はコマンドライン(command line)（CLI）のみですEchoLab は今(いま)のところ、ターミナル(terminal)で python -m core.agent "質問" と入(にゅう)力(りょく)して使(つか)います。画(が)面(めん)（GUI）はありません。Web 画(が)面(めん)はロードマップ(roadmap)の M5 で予(よ)定(てい)している機(き)能(のう)で、まだ実(じっ)装(そう)されていません（今(こん)後(ご)の機(き)能(のう)（ロードマップ(roadmap)）を参(さん)照(しょう)）。
表(ひょう)示(じ)言(げん)語(ご)についてCLI のメッセージ(message)や出(しゅつ)力(りょく)（状態、出典、差し戻し など）は日(に)本(ほん)語(ご)です。このガイド(guide)では実(じっ)際(さい)の出(しゅつ)力(りょく)をそのまま載(の)せ、各(かく)部(ぶ)分(ぶん)の意(い)味(み)を説(せつ)明(めい)します。

数(すう)字(じ)を信(しん)頼(らい)できる理(り)由(ゆう)

数(すう)字(じ)はツール(tool)だけが出(だ)す

AI は計(けい)算(さん)を一(いっ)切(さい)しません。2 つの数(かず)の差(さ)や増(ぞう)加(か)率(りつ)も、比(ひ)較(かく)ツール(tool)（compare.diff / compare.ratio）に計(けい)算(さん)させます。

検(けん)証(しょう)器(き)が 1 つずつ照(しょう)合(ごう)

AI が書(か)くのはプレースホルダ(placeholder)（例(れい)：[[c1.total|0]]）入(い)りの下(した)書(が)きです。出(しゅっ)典(てん)のない数(すう)字(じ)が下(した)書(が)きにあれば「差(さ)し戻(もど)し」となり、書(か)き直(なお)しになります。

出(しゅっ)典(てん)の表(ひょう)でたどれる

どの数(すう)字(じ)にも出(しゅっ)典(てん) ID（例(れい)：c3.diff）があり、元(もと)の値(あたい)と計(けい)算(さん)したツール(tool)が回(かい)答(とう)の下(した)に並(なら)びます。

未(み)確(かく)認(にん)のデータ(data)は注(ちゅう)記(き)

サンプルデータ(sample data)の多(おお)くは verified: false です。これを使(つか)った場(ば)合(あい)は、回(かい)答(とう)の末(まつ)尾(び)に「未(み)確(かく)認(にん)のサンプルデータ(sample data)に基(もと)づいています」という注(ちゅう)記(き)が自(じ)動(どう)で付(つ)きます。

直(なお)らなければ数(すう)字(じ)を出(だ)さない

3 回(かい)差(さ)し戻(もど)しても合(ごう)格(かく)しないときは、疑(うたが)わしい数(すう)字(じ)を出(だ)す代(か)わりに、数(すう)値(ち)を含(ふく)まない定(てい)型(けい)の回(かい)答(とう)だけを返(かえ)します（状(じょう)態(たい) fallback）。

実(じっ)際(さい)の Claude を呼(よ)ぶときは、呼(よ)び出(だ)しのたびに 1 日(ひ) 1 ドル(dollar)・1 か月(げつ) 10 ドル(dollar)の上(じょう)限(げん)を確(かく)認(にん)します（環(かん)境(きょう)変(へん)数(すう)で変(へん)更(こう)できます）。
