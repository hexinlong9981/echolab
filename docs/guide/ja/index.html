はじめに概要

EchoLab とは

「AI に計算させない」コマンドラインの質問応答アシスタントです。質問を 1 文で入力すると、数値はすべて決定的な計算ツールが求め、回答に出てくるどの数字についても出典をたどれます。

できること

EchoLab は『鳴潮（Wuthering Waves）』の育成を題材にした、非公式・非営利のファン作品です。ターミナルで質問を入力すると、次のように動きます。

  • 質問を理解し、適切な計算ツール（期待ダメージ、声骸のスコア、ガチャの確率、差や増加率を求める比較ツール）を選びます。
  • ツールに計算させ、その結果を使って説明文を書きます。
  • 回答の下に出典の表を付けます。それぞれの数字がどの計算から来たか、元の値はいくつか、未確認のデータを使ったかどうかがわかります。
現在はコマンドライン（CLI）のみですEchoLab は今のところ、ターミナルで python -m core.agent "質問" と入力して使います。画面（GUI）はありません。Web 画面はロードマップの M5 で予定している機能で、まだ実装されていません（今後の機能（ロードマップ）を参照）。
表示言語についてCLI のメッセージや出力（状態、出典、差し戻し など）は日本語です。このガイドでは実際の出力をそのまま載せ、各部分の意味を説明します。

数字を信頼できる理由

数字はツールだけが出す

AI は計算を一切しません。2 つの数の差や増加率も、比較ツール（compare.diff / compare.ratio）に計算させます。

検証器が 1 つずつ照合

AI が書くのはプレースホルダ（例：[[c1.total|0]]）入りの下書きです。出典のない数字が下書きにあれば「差し戻し」となり、書き直しになります。

出典の表でたどれる

どの数字にも出典 ID（例：c3.diff）があり、元の値と計算したツールが回答の下に並びます。

未確認のデータは注記

サンプルデータの多くは verified: false です。これを使った場合は、回答の末尾に「未確認のサンプルデータに基づいています」という注記が自動で付きます。

直らなければ数字を出さない

3 回差し戻しても合格しないときは、疑わしい数字を出す代わりに、数値を含まない定型の回答だけを返します（状態 fallback）。

コストの上限つき

実際の Claude を呼ぶときは、呼び出しのたびに 1 日 1 ドル・1 か月 10 ドルの上限を確認します（環境変数で変更できます）。

1 回の質問の流れ（アニメーション）

付属の例「2 つのビルドのどちらが強いか比べる」を使って、1 回の質問の流れを示します。「次へ」で 1 ステップずつ、または「自動再生」でご覧ください。

実際の実行の様子

同じ例を実際に実行したときの出力です（台本モード＋実際の Java 計算サービス。API キーは要りません）。コマンドが長いのは、2 つのビルドのパラメータをすべて質問に書いているためです。

出力の読み方：上半分が回答です。出典: の下の表には、回答が引用した数字ごとに出典 ID、元の値、計算したツール、使った未確認のデータ（- はなし）が並びます。最後の行が状態です。費用: $0.0000 となっているのは、台本モードでは実際の AI を呼ばないためです。各項目の詳しい説明は回答の読み方をご覧ください。

未確認のデータを使ったとき

計算に verified: false のサンプルデータ（例：限定キャラクターのガチャのルール）を使うと、回答に注記の行が自動で加わり、出典の表の「未確認データ」列にどのデータかが示されます。

（my-unverified.yaml はこの説明のために用意した台本で、ツールに banner: featured-character を指定してサンプルのガチャデータを参照させています。台本の書き方は実行トレースと評価をご覧ください。）
