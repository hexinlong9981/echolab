EchoLab のコア(core)（ゲートウェイ(gateway)、検(けん)証(しょう)器(き)、評(ひょう)価(か)、トレース(trace)）は、ゲーム(game)の概(がい)念(ねん)を一(いっ)切(さい)含(ふく)みません。ドメイン(domain)の知(ち)識(しき)はすべて「ドメインパック(domain pack)」に置(お)き、使(つか)えるツール(tool)を domain.yaml で宣(せん)言(げん)します。M3 では、ごく小(ちい)さな住(じゅう)宅(たく)ローン(loan)のパック(pack)でこれを実(じっ)証(しょう)する予(よ)定(てい)です：

  • 予(よ)定(てい)している内(ない)容(よう)：元(がん)利(り)均(きん)等(とう)返(へん)済(さい)と元(がん)金(きん)均(きん)等(とう)返(へん)済(さい)の比(ひ)較(かく)、繰(く)り上(あ)げ返(へん)済(さい)の効(こう)果(か)。計(けい)算(さん)部(ぶ)分(ぶん)は Python で書(か)き、同(おな)じくゴールデンケース(golden case)とプロンプト(prompt)を用(よう)意(い)します。
  • 目(もく)標(ひょう)：新(あたら)しいコード(code)は約(やく) 300 行(こう)、コア(core)の差(さ)分(ぶん)はゼロ(zero)。「このパック(pack)を加(くわ)えても core/ が変(か)わっていない」ことを CI で検(けん)査(さ)します。
  • README と回(かい)答(とう)の両(りょう)方(ほう)に、これは計(けい)算(さん)の例(れい)であり、金(きん)融(ゆう)に関(かん)する助(じょ)言(げん)ではないことを明(めい)記(き)します。
