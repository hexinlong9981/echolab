Home: choose how to run

Get EchoLab running on your own computer: fetch the code, set up a Python environment, then pick a path based on what you have (a JDK 21 or not, an Anthropic API key or not). The shortest path needs only Python and shows you a first answer with sources within a few minutes.

What "running locally" means

EchoLab has no server to deploy. "Running locally" means running python -m core.agent "question" from the repository root. That process does everything on your machine, in order: the LLM decides which tools to call → the tools calculate → the verifier checks the draft → the renderer fills in the numbers → the answer and the source table are printed. It also writes a trace to .echolab/traces/ on your machine.

Two parts can be swapped out, and combining them gives three paths:

  • The LLM part: either a script written in advance (--llm scripted --script script.yaml; no network, no cost) or real Claude (the default, --llm anthropic).
  • The calculation part: either the Python reference implementation used in tests (--fake-backend, calculated in the same process) or the real Java calc service, calc-engine (the CLI starts it as a subprocess according to config/services.yaml and talks to it over MCP stdio).

Whichever path you choose, the gateway (tool allowlist, numbering of call IDs and source IDs), the compare tools, the numeric verifier, the renderer and the traces are the same real code.

Tip: run path A once first, whichever path you end up onPath A does not depend on Java or the network (except when installing dependencies), so it is the quickest way to confirm that your Python environment and the code itself work. Windows usersAll commands in this guide run in WSL's Linux. Never used WSL? Start with Set up WSL on Windows.

Below is a real session on a fresh Linux (WSL2) environment. Dependencies were installed with -q, which prints almost nothing on success. The path has been shortened to ~/echolab.

The question and answer are in Japanese, because the bundled script is. The question asks which of two builds is stronger and by how much (build A: ATK 2000, skill multiplier 2.5, damage bonus 0.3, crit rate 0.6, crit damage 2.2, enemy DEF 1000, no RES shred; build B: ATK 1800, skill multiplier 3.0, damage bonus 0.2, crit rate 0.5, crit damage 2.5, enemy DEF 1200, RES shred 0.3; both with DEF constant 1600, DEF ignore 0, enemy RES 0.1). The answer says "Build B is stronger", gives the expected damage of A (6,192) and B (7,128), and the difference: 936 (15.1% more than A).

For how to read each part of the answer and the source table, see Reading the answers in the user guide. The source table headers, the status line and error messages are in Japanese (the project's interface language): 「出典」 = sources, 「状態」 = status, 「差し戻し」 = rejected drafts, 「費用」 = cost, 「実行 ID」 = run ID, 「トレース」 = trace, 「未確認データ」 = unverified data. In scripted mode, the language of the answer text is set by the script; this bundled example is in Japanese.
