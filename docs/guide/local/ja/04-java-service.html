1. JDK 21 をインストール(install)する

JDK 21 であれば、どのディストリビューション(distribution)でもかまいません。ここでは Eclipse Temurin を例(れい)に、アーカイブ(archive)を使(つか)ってホームディレクトリ(home directory)の下(した)にインストール(install)します。root 権(けん)限(げん)は要(い)りません（x64 の Linux／WSL2 の場(ば)合(あい)です。ほかのプラットフォーム(platform)では Adoptium のサイト(site)で該(がい)当(とう)するパッケージ(package)を選(えら)んでください。macOS なら Homebrew で temurin@21 を入(い)れることもできます）。

mkdir -p ~/.local/jdk
curl -L -o /tmp/temurin21.tar.gz \
  https://api.adoptium.net/v3/binary/latest/21/ga/linux/x64/jdk/hotspot/normal/eclipse
tar -xzf /tmp/temurin21.tar.gz -C ~/.local/jdk        # jdk-21.0.12.1+1 のようなディレクトリができる（バージョン番号は変わる）
ln -sfn ~/.local/jdk/jdk-21.0.12.1+1 ~/.local/jdk/21  # バージョン番号を含まない固定のパスを作っておくと、更新が楽になる
echo 'export JAVA_HOME=$HOME/.local/jdk/21' >> ~/.bashrc
export JAVA_HOME=$HOME/.local/jdk/21

ダウンロード(download)するアーカイブ(archive)は約(やく) 198 MB です。~/.bashrc に書(か)いておけば、新(あたら)しく開(ひら)いたターミナル(terminal)では JAVA_HOME が自(じ)動(どう)で設(せっ)定(てい)されます。
