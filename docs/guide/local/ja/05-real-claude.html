5. 上(じょう)限(げん)に達(たっ)するとどうなるか

コスト(cost)の確(かく)認(にん)は Claude を呼(よ)ぶ前(まえ)に行(おこな)われ、認(にん)証(しょう)情(じょう)報(ほう)を使(つか)うよりも先(さき)です（core/agent/loop.py の _call_llm は、まず budget.check() を実(じっ)行(こう)します）。そのため、お金(かね)もキー(key)も使(つか)わずに再(さい)現(げん)できます。1 日(ひ)の上(じょう)限(げん)を 0 にし、本(ほん)物(もの)の台(だい)帳(ちょう)に触(ふ)れないよう、台(だい)帳(ちょう)を一(いち)時(じ)ファイル(file)に向(む)けます。

コマンド(command)の「…（同(どう)上(じょう)）…」は紙(し)面(めん)の都(つ)合(ごう)で省(しょう)略(りゃく)したもので、実(じっ)際(さい)には質(しつ)問(もん)の全(ぜん)文(ぶん)を入(にゅう)力(りょく)しています。

  • 認(にん)証(しょう)情(じょう)報(ほう)がなくても、結(けっ)果(か)は llm_error ではなく budget_exceeded になります。上(じょう)限(げん)の確(かく)認(にん)が先(さき)にあり、Claude はまったく呼(よ)ばれていないからです。トレース(trace)にも llm_call や llm_error のイベント(event)はありません。
  • 回(かい)答(とう)には、どの上(じょう)限(げん)か（今(こん)日(にち)＝日(にち)次(じ)）、使(し)用(よう)額(がく)と上(じょう)限(げん)、いつ使(つか)えるようになるか、変(へん)更(こう)の方(ほう)法(ほう)が示(しめ)されます。ECHOLAB_MONTHLY_USD=0 にした場(ば)合(あい)は、回(かい)答(とう)が「今(こん)月(げつ)（UTC）のコスト(cost)が月(げつ)次(じ)の上(じょう)限(げん)に達(たっ)したため…」に変(か)わります。
  • 一(いち)時(じ)的(てき)な台(だい)帳(ちょう)ファイル(file)は作(つく)られていません。呼(よ)び出(だ)しがなければ、記(き)録(ろく)することもないからです。
  • 1 回(かい)の質(しつ)問(もん)の途(と)中(ちゅう)で上(じょう)限(げん)に達(たっ)した場(ば)合(あい)（たとえばツール(tool)を呼(よ)んだ後(あと)、2 回(かい)目(め)に Claude を呼(よ)ぶ前(まえ)）も、同(おな)じく budget_exceeded で終(お)わります。それまでにかかった費(ひ)用(よう)は、そのまま台(だい)帳(ちょう)に記(き)録(ろく)されます。
