1. Windows のバージョン(version)と仮(か)想(そう)化(か)を確(たし)かめる

2. WSL と Ubuntu をインストール(install)する

スタートメニュー(Start menu)で PowerShell（または Windows Terminal）を探(さが)して右(みぎ)クリック(click)し、「管(かん)理(り)者(しゃ)として実(じっ)行(こう)」を選(えら)んで、次(つぎ)のように入(にゅう)力(りょく)します。

PowerShell（管(かん)理(り)者(しゃ)）。Windows 側(がわ)のコマンド(command)はコマンド(command)だけを示(しめ)し、出(しゅつ)力(りょく)例(れい)は載(の)せていません。

Microsoft のドキュメント(document)によると、このコマンド(command) 1 つで次(つぎ)のことが行(おこな)われます。「Linux 用(よう) Windows サブシステム(subsystem)」と「仮(か)想(そう)マシン(machine) プラットフォーム(platform)」の 2 つのオプション(option)機(き)能(のう)を有(ゆう)効(こう)にする。最(さい)新(しん)の Linux カーネル(kernel)をダウンロード(download)してインストール(install)する。WSL 2 を既(き)定(てい)のバージョン(version)にする。Ubuntu ディストリビューション(distribution)をダウンロード(download)してインストール(install)する。途(と)中(ちゅう)でパソコン(PC)の再(さい)起(き)動(どう)が必(ひつ)要(よう)になるので、案(あん)内(ない)に従(したが)って再(さい)起(き)動(どう)してください。

初(しょ)回(かい)の起(き)動(どう)：Linux のユーザー(user)を作(つく)る

再(さい)起(き)動(どう)したら、スタートメニュー(Start menu)から Ubuntu を開(ひら)きます（または Windows Terminal で Ubuntu のタブ(tab)を開(ひら)きます）。初(しょ)回(かい)の起(き)動(どう)ではまずファイル(file)の展(てん)開(かい)を待(ま)ち、そのあと新(あたら)しいユーザー(user)名(な)とパスワード(password)の入(にゅう)力(りょく)を求(もと)められます。知(し)っておきたい点(てん)は次(つぎ)のとおりです（いずれも Microsoft のドキュメント(document)によります）。

  • このユーザー(user)名(な)とパスワード(password)はこの Linux ディストリビューション(distribution)専(せん)用(よう)で、Windows のユーザー(user)名(な)やパスワード(password)とは関(かん)係(けい)ありません。別(べつ)のものにしてかまいません。
  • パスワード(password)の入(にゅう)力(りょく)中(ちゅう)は画(が)面(めん)に何(なん)も表(ひょう)示(じ)されません（* も出(で)ません）。これは正(せい)常(じょう)なので、入(にゅう)力(りょく)し終(お)えたら Enter キー(key)を押(お)してください。
  • このアカウント(account)はディストリビューション(distribution)の既(き)定(てい)のユーザー(user)になり、起(き)動(どう)時(じ)に自(じ)動(どう)でサインイン(sign in)します。Linux の管(かん)理(り)者(しゃ)でもあり、sudo で管(かん)理(り)用(よう)のコマンド(command)を実(じっ)行(こう)できます。以(い)後(ご) sudo が求(もと)めるパスワード(password)は、ここで設(せっ)定(てい)したパスワード(password)です。
  • パスワード(password)を忘(わす)れた場(ば)合(あい)：PowerShell で wsl -u root を実(じっ)行(こう)して root として入(はい)り、passwd <ユーザー名> で設(せっ)定(てい)し直(なお)してから exit します。

3. インストール(install)結(けっ)果(か)を確(たし)かめる

Microsoft のドキュメント(document)では、WSL 1 と WSL 2 の間(あいだ)の変(へん)換(かん)には時(じ)間(かん)がかかることがあり、失(しっ)敗(ぱい)することもあると注(ちゅう)意(い)されています。ディストリビューション(distribution)に大(だい)事(じ)なファイル(file)がすでにある場(ば)合(あい)は、先(さき)にバックアップ(backup)を取(と)ってください。インストール(install)したばかりの空(そら)のディストリビューション(distribution)なら心(しん)配(ぱい)はいりません。

5. リポジトリ(repository)をどこに置(お)くか

リポジトリ(repository)は Ubuntu のホームディレクトリ(home directory)、たとえば ~/echolab（つまり /home/<ユーザー名>/echolab）にクローン(clone)してください。/mnt/c/…（Windows の C ドライブ(drive)）の下(した)には置(お)かないでください。

  • 速(そく)度(ど)：Microsoft は、Linux のツール(tool)で扱(あつか)うファイル(file)は WSL のファイルシステム(file system)に置(お)くよう勧(すす)めています。OS をまたいだファイル(file)へのアクセス(access)もできますが、かなり遅(おそ)くなることがあります。依(い)存(ぞん)パッケージ(package)のインストール(install)やテスト(test)の実(じっ)行(こう)では小(ちい)さなファイル(file)を大(たい)量(りょう)に読(よ)み書(か)きするため、違(ちが)いがはっきり出(で)ます。
  • 動(どう)作(さ)をそろえる：/mnt/c の下(もと)では、ファイル(file)の権(けん)限(げん)や大(だい)文(も)字(じ)・小(しょう)文(も)字(じ)の区(く)別(べつ)などが Windows のファイルシステム(file system)の規(き)則(そく)に従(したが)うため、CI の Linux 環(かん)境(きょう)とは違(ちが)ってきます。

クローン(clone)の具(ぐ)体(たい)的(てき)なコマンド(command)は セットアップ(setup) をご覧(らん)ください。クローン(clone)の前(まえ)に cd ~ でホームディレクトリ(home directory)に戻(もど)っておけば大(だい)丈(じょう)夫(ぶ)です。
