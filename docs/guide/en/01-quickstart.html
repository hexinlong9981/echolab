Step 1: Get the code

git clone https://github.com/hexinlong9981/echolab.git
cd echolab

Step 2: Python virtual environment and dependencies

To use the CLI, installing requirements.txt is enough (requirements-dev.txt adds development tools such as pytest and ruff).

If you see the help text (its description line 「出典付きで質問に答える」 means "answer questions with sources"), the installation worked. Each time you open a new terminal, first run source .venv/bin/activate in the repository root; python in the rest of this guide means the Python inside the virtual environment.

Step 3: Your first question (no key, no Java)

Two switches let the demo run entirely on your machine:

  • --llm scripted --script script.yaml: does not call a real AI; instead it "plays" the AI by following the steps written in the script file.
  • --fake-backend: does not start the Java calculation service; it calculates with the Python reference implementation used for testing.

The bundled example question and script are in Japanese. The question compares two builds by expected damage, and the answer reads: "Build B is stronger. Build A expected damage: 6,192. Build B expected damage: 7,128. Difference: 936 (15.1% more than A)." Below it come the source table (出典) and the status line (状態 = status, 差し戻し = rejected drafts, 費用 = cost, 実行 ID = run ID, トレース = trace file). See Reading the answers for every field.

Answers in scripted mode are written in advanceScripted mode is only a demo: which tools the AI calls and what drafts it writes are fixed by the script and have nothing to do with the question you type. For example, if you change the question to 「こんにちは」 ("hello"), the same script still gives the answer above. Actually understanding a question requires the real Claude from step 5.

Note 差し戻し: 1 回 (1 rejected draft): this script deliberately has the first draft write a number it worked out itself (936). The verifier rejects it, and the second draft passes only after it uses the compare tools.

Step 4: Connect the real Java calculation service

Without --fake-backend, the CLI follows config/services.yaml and starts java -jar services/calc-engine/build/libs/calc-engine-mcp.jar as a child process. That requires JDK 21 and a built jar.

  1. Install JDK 21 (a distribution package or a Temurin archive both work). The example below unpacks the JDK into $HOME/.local/jdk/21.
  2. Set JAVA_HOME. Even if java is not on your PATH, the CLI falls back to $JAVA_HOME/bin/java as long as JAVA_HOME points to the JDK.
  3. Build the jar in services/calc-engine (the first build downloads Gradle and dependencies, so it needs network access).

Then ask again with the same question and script, but without --fake-backend. Because a Java process has to start, the whole run took about 9 seconds in the verification environment.

The answer and the source table are exactly the same as in step 3: the fake service, like the Java service, returns values such as expected damage with 6 decimal places (banker's rounding, HALF_EVEN), for example 6192.000000. In the command, 「…（同上）…」 ("…same as above…") marks an omission; type the full question in practice.

If you get エラー: サービス calc-engine の実行ファイル java が見つかりません。("Error: the executable java for service calc-engine was not found.") then there is no java on your PATH and JAVA_HOME is not set. If you get jar がありません ("the jar does not exist"), the jar has not been built yet. In both cases the CLI stops before starting Java, prints only a short explanation and how to fix it, and exits with code 2. See Troubleshooting & FAQ.

Step 5 (optional): Use the real Claude

Without --llm, the default is anthropic, which calls the real Claude (model claude-opus-5-5). You can then ask freely, and Claude decides which tools to call.

5-1 Set up credentials

Credentials are looked up in the default order of Anthropic's official Python SDK. The two simplest options:

# Option A: environment variable
export ANTHROPIC_API_KEY=sk-ant-...(your key)

# Option B: log in with Anthropic's CLI (the SDK reads the configuration it saves)
ant auth login

What happens if you run without credentials? Below is the real output: the CLI does not crash. It ends with status llm_error and exit code 1, and the answer states the cause and the fix directly.

The question asks for the expected damage at ATK 2000. The answer means: "Could not answer because no Claude API credentials were found. Set the environment variable ANTHROPIC_API_KEY (or log in with ant auth login), or use scripted mode (--llm scripted), which needs no API key." （引用した出典はありません） means "no sources were cited". The trace line records "kind": "credentials" and the error "Claude API credentials not found (set ANTHROPIC_API_KEY or similar)".

The answer depends on the causeFor llm_error, the answer differs by the SDK's exception type: with no credentials or failed authentication (HTTP 401/403), it tells you to set ANTHROPIC_API_KEY or use ant auth login; only for rate limits, overload or network problems does it say 「時間をおいてお試しください」 ("please try again later"); for other API errors it points you to the trace. The trace's llm_error line contains the category kind and the SDK's original error message.

5-2 Set cost caps first

Before every call to Claude, the CLI checks the cost ledger (by default .echolab/costs.jsonl). The default caps are in config/budget.yaml: 1.00 USD per day and 10.00 USD per month, with days counted in UTC (the day rolls over at 00:00 UTC). For your first try you can set them even lower temporarily:

export ECHOLAB_DAILY_USD=0.20     # at most 0.20 USD today
export ECHOLAB_MONTHLY_USD=2.00   # at most 2.00 USD this month

Once a cap is reached, Claude is no longer called and the run ends with status budget_exceeded. How cost is computed and the ledger format are described in Cost caps & data trust.

5-3 Ask a question

python -m core.agent "What is the expected damage, with a breakdown, for ATK 2000, skill multiplier 2.5, DMG bonus 0.3, crit rate 0.6, crit DMG 2.2, defense constant 1600, enemy DEF 1000, DEF ignore 0, enemy RES 0.1 and RES shred 0?"

(The verification environment for this guide has no API key, so no real Claude answer is shown here; the format is the same as in scripted mode above.) Claude writes the answer text in the language of your question, while the labels and fixed messages stay in Japanese. Put every parameter the calculation needs into the question: the tools can only calculate with values you give or with the sample data that ships with the project.

PrivacyYour question, the system prompt and the tools' results are sent to Anthropic only in anthropic mode. Scripted mode runs entirely on your machine. The trace of every run is saved locally in .echolab/traces/.
